# Add a layout

Layouts are in `components/hid/layouts_data.c`, generated by `tools/gen_layouts.py`. Do not edit the generated file by hand.

1. Open `tools/gen_layouts.py` and add a table like `IT`: four rows of physical keys, each with four levels (normal, Shift, AltGr, AltGr+Shift). Keys are identified by the HID usage of the US position; `·` = no character.
2. Add `("name", TABLE)` to `LAYOUTS`.
3. If the layout behaves differently per operating system, add the sources:
   - `linux_altgr` (xkb levels) or `linux_extra` for Linux;
   - `windows_klc`: KLC file from Microsoft Keyboard Layout Creator;
   - `mac_dump`: dump produced by `tools/dump_mac_layout.c` on a Mac (see `tools/layouts/README.md`).
4. Regenerate: `python3 tools/gen_layouts.py`.
5. Add tests in `test/host/test_main.c` with `expect_key` and check: `make -C test/host`.
6. Add the name to the selectors in `apps/webhid/web/index.html`.

Record in `tools/layouts/README.md` the source of every piece of data not written by hand, with its address and, if it is a downloaded file, its hash.

How dead keys and levels work: [Layouts, operating systems and dead keys](../explanation/layouts-and-dead-keys.md).
